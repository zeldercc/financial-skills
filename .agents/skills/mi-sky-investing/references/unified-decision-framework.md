# 统一投资操作框架：2026-11-04重新梳理

目的：把Mi姐长期思想、可计算的股票技术面以及独立缠论参考体系合成**一套可以实际用于研究和复盘、但不会伪造信号**的流程。原始资料在用户授权的Google Drive文件夹；公开仓库仅保留独立归纳与来源代码。

## 0. 数据和来源入口

先记录交易所/代码、用户当前是否持有、成本与投资期限、行情观察日、数据商、复权方式。先核实最新披露（财报、公告、停复牌）和真实行情，未取得分时K/成本分布时不计算其相关指标。

每条技术结论必须注明：
- **Mi姐观点**：T00、T07、T08、P01等，明确条目、当时日期、投资周期。
- **缠论理论**：C01、C02，说明与Mi姐表述不同或相同的地方，**不称Mi姐原创**。
- **计算定义**：如MA离散度、RVOL20、支撑共振容差、pivot确认周期，必须列参数。
- **外部事实**：交易所、正式财报、具时间戳的市场数据，附原始网址。
- **假设**：个人风险预算、目标收益、策略参数、对行业的推论，明确是否未知。

## 1. 先判断能否参与

1. 宏观/大盘：流动性、风险偏好、主要指数月/周趋势及市场成交额。T07 §338；T08 §449、§458。
2. 产业与板块：景气、需求、订单、盈利周期，板块与大盘的相对强弱。T07 §338；T08 §452。
3. 基本面：财务质量、真实竞争优势、估值位置及基本面反证。T00 §196；T08 §452。
4. 股性分类：趋势型/情绪型/难判断。严格按公开行情描述，不推断真实“主力持仓”。T00 §100-103、§296。

如果行业/估值/流动性存在强烈反证，可以保留研究价值，但不可用微观金叉替代投资价值判断。

## 2. 七级别价格行为诊断

| 观察层 | 目标 | 必须展示 |
|---|---|---|
| 月线 | 大周期位置、箱体、长期均线粘合/发散与长期风险 | 已完成月K、MA5/10/20、月线结构关键价 |
| 周线 | 趋势与中期持仓框架 | 周前高/前低、MA方向、箱体颈线及失效 |
| 日线 | 主要交易结构 | MA5/10/20/60/120/250、斜率、RVOL、成交量与平台突破 |
| 120分钟 | 半日方向过滤与中等级别价格带 | 前高/前低、MA20/60、支撑与收盘确认 |
| 60分钟 | 耐心寻找入场时机 | 回踩低点抬升、支撑、放量突破、MACD辅助 |
| 30分钟 | 观察阶段性动能衰减和卖出风险 | 前高/前低、量价背离、结构破坏 |
| 5分钟 | 更细的执行位置 | 仅已完成K线、小级别转折候选与交易制度 |

来源 T00 §85、§257，T08 §458，P01 2026-10-26 60/120分钟推文。七级别并不总是能获取；缺失一层必须标记，不能拿其他层代替。

均线粘合：同级MA5、MA10、MA20的离散度=(最大值-最小值)/|MA20|；与5根K线前比较。没有用户指定阈值不输出“已粘合=是”。这是独立计算定义，非Mi姐原始指标。

## 3. 两套结构观察必须并列，不得混写

**轨道A，传统量价结构**：
- 以事先固定的局部高低点、日/周箱体上下沿、前高颈线、均线、趋势线、真实成交密集区、外部筹码成本峰汇总支撑压力。
- 结合放量突破、回踩守住、收盘有效性及后续K线（T07 §339：1至3根仅作参考，不是硬性）。
- 考虑头肩底/W底、上升旗形、三角形、520均线回踩及高位放量破位，均需各自证据。

**轨道B，缠论严格结构**：
- 先明确K线包含关系、分型、笔、线段及走势类型的定义，确认**次级别走势段已完成**。
- 由至少三个连续已完成次级走势类型的重叠构成中枢，标明ZD和ZG；未能核实段完成状态则不可称严格中枢。
- 一买/一卖看该级别严格趋势背驰；二买/二卖看第一类买卖点后的次级别反抽/回试结束；三买看向上离开并首次回试低点不低于ZG，三卖看向下离开并首次反抽高点不高于ZD。
- 仅有5分钟K线或普通箱体形态，不能生成“正式三买”；可报告普通突破/回踩候选及缺失分段数据。
- 使用scripts/chan_segment_check.py只做人工输入次级走势段的三段重叠和五段几何模板检查，**不会自动分笔、分线段或认证买卖点**。
- 对缠论“必然、100%”理论主张不套用为交易收益概率。

来源 C01/C02、第20/21课；T00 §177、§179对三买的简化应用须标注为Mi姐口径。

## 4. 重要支撑压力的交叉验证

按形成来源分别列：
- 月/周结构、关键颈线、历史高低点与已结束缺口。
- 日/120/60/30/5分MA及局部高低点，注明具体周期和确认日期。
- 量能价位分布：基于真实细粒度成交才能估算成交密集区；5分钟OHLCV只可作粗略VP代理。
- 筹码成本峰：必须从券商/数据商取得当期及（如有）上期的成本分布快照，注明模型，不能称所有股东真实成本。
- 同一价位附近聚合时明确容差（如0.5%为研究参数，不是作者规定）；支撑与压力失效后需要重新识别。
- 多个价格/均线指标通常高度相关，不能简单把数量当独立证据或“高胜率”。

## 5. 五类入场及七类退出

入场分开讨论：趋势缩量回踩、平台放量突破并回踩、W底/头肩底颈线、月线长期箱体主升启动、基本面左侧价值试错；缠论一/二/三买另列，前提是结构严格核验。T00 §61/128/196/296；T07 §320/339；T08 §426。

退出观察：高位放量破位、头肩顶/双顶颈线、日/周关键趋势线和MA失守、冲高长上影、反弹高点降低、下跌趋势B浪反弹至压力、按重要回调低点移动保护水平。T00 §59/62/101/214；T08 §427。

买入和卖出策略必须同周期：价值买入对应企业经营/估值逻辑失效，技术入场对应技术结构失效；不允许短线被套后突然改称长线。T00 §129；T08 §438。

## 6. 对用户的标准化结论

每只股票以七段输出：
1. **现在是大盘/行业的哪个周期**，提供事实来源和重要反证。
2. **股票价值与技术适配度**分别给结论，不能混为一谈。
3. **七级别趋势与指标表**，不足的数据写缺失。
4. **重要支撑/压力价格带**，逐级别列证据、日期和失效方式。
5. **量价、筹码分布和缠论双轨**，明确哪些是已确认、候选或不可判断。
6. **入场、分批、持有、减仓、退出三情景**，有具体结构条件但不杜撰成交价及账户风险预算。
7. **来源与复盘清单**，至少两条反面证据，并列数据来源、Mi姐观点、独立缠论原典、推论。

## 7. 历史验证要求

- 价格信号只能用当时已完成的K线；pivot必须等待右侧已完成K线才算确认。
- 财报用真实公告披露日；按当时成分股复原RPS股票池，不能混用事后名单。
- K线重采样遵守9:30-11:30、13:00-15:00分段及收盘集合竞价；特殊停复牌/异常交易日不可无提示静默补齐。
- 模型需要独立样本外测试并计入费用、滑点、涨跌停无法成交及A股证券类别T+1限制；没有回测不给胜率。
- 原始历史书例的绝对点位（如历史上证指数价格）不得复用到2026年行情，必须每次按真实行情重新确定。
