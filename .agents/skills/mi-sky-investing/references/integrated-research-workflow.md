# 股票研究全流程（2026-11-04资料重整版）

此文件作为每次启动 mi-sky-investing 的主流程。按“市场与行业→企业及估值→多周期技术→候选买卖点→仓位与风控→证据和复盘”顺序执行；各专项细节交给对应references文件。来源索引见source-index.md。

## 1. 源头与历史判断优先级

- 对 Mi姐本人的**历史观点**：优先可定位日期的P01完整推文时间线，其后T00/T01-T08及M01-M08；P02/P03是P01的分类与精华重复稿，不可重复当成多个独立证据。
- 对缠论**术语定义**：C01《教你炒股票108课》优先，C02汇编用于辅助检索，Mi姐T00中简化应用另行标注；不能因为后文日期较新就推翻原典定义。
- 对**当前事实**：证监会、交易所、上市公司公告、财报、官方指数、原始行情与政策时间戳优先。推文的“当时看涨/看跌”只是历史判断，不是今天的买卖信号。
- 所有观点加标签：[Mi姐原意]、[缠论原典]、[独立推演]、[外部事实]、[用户参数]。保留反对证据与可能的原文冲突。

## 2. 第一层：大盘、流动性、板块、企业

1. 大盘：月/周方向、市场成交额增减、主要指数表现、宏观流动性、风险偏好和政策；判断趋势、箱体还是下行，决定组合主动风险是否合适。
2. 行业：中期景气、供需、业绩兑现、估值分位、行业指数相对大盘强弱，标出龙头与可能的轮动催化；不能将“政策支持”直接等于盈利。
3. 公司：商业模式、行业竞争优势、营收及利润质量、毛利率、ROE、自由现金流、应收/存货、债务与现金流，分清产业地位、技术壁垒与估值。
4. 估值：使用适合行业的估值方法并与同业/历史比较，避免将热门题材或价格跌幅等同便宜。
5. 策略类别：长线基本面、波段趋势、短线情绪、震荡区间，四者建仓和退出逻辑不同。T07 §338、T08 §438/§452/§458。

## 3. 第二层：选股过滤，不直接排名买入

- 第一轮：行业逻辑与盈利质量，剔除关键事实不可验证、流动性/治理问题和不可交易标的。
- 第二轮：T00 §196文章的强势股筛选（MA20>MA60>MA120、RSI>50、MACD、VMA5>VMA10、突破放量、净利润增长），所有阈值均属于该文参考，不能宣称通用最优。
- 第三轮：月线长期箱体、周线W底/颈线、日线缩量回踩或放量突破及量价时确认。T00 §128/§296、T07 §320/§339。
- 第四轮：RPS需指定股票池与窗口；筹码模型和所谓主力资金净流入需写数据商及计算口径，不能用“持仓已被证实”的语气报告。
- 输出“不满足、待确认、满足研究候选、数据不足”的逐项证据，不输出未经验证的自动买入评级。

## 4. 第三层：七级别走势矩阵

按月→周→日→120分钟→60分钟→30分钟→5分钟逐级输出：
- 各周期真实的已完成K线时间、收盘、MA5/10/20/60/120/250（历史不足时NA）、均线方向、斜率、MA5/10/20离散度与收敛/发散变化。
- 前高/前低、最近有效pivot、箱体/颈线、长短周期动态均线支撑、压力位，形成与确认日期。
- 相对成交量RVOL、上涨放量/下跌缩量、放量跌破与假突破，MACD、RSI、ATR和布林带宽度（数值可得时）。
- 价格成交量分布POC/VAH/VAL（需明确是真实逐笔还是5分钟典型价粗分桶）与外部筹码成本峰（数据商、模型、日期）。
- 多级别支撑共振以用户指定容差合并，并列出具体支撑价带、周期数、指标来源，不能将重叠价位视为已验证胜率。
- 大周期强而小周期弱，通常只意味着短线调整候选；大周期弱而小周期强，可能仅是反弹。不得以5分K线金叉代替月线反转。
- 5分数据必须在真实交易时段，120分不跨午休；不完结的30/60/120、周/月级别一律不得作为已收盘确认。详细见multi-timeframe-and-chips.md。

## 5. 第四层：不同交易模式的入场资格

| 场景 | 必须同时满足的关键要素 | 失效与后续 |
|---|---|---|
| 月/周大箱体突破 | 大周期长期整理、箱体边界已知、放量收盘突破、后续回踩/站稳，行业支持 | 跌回箱体并继续弱于行业即撤销启动假设 |
| 520/趋势回踩 | 周月结构向上、日MA20或趋势支撑附近缩量、低点未有效失守、60分再转强 | 放量跌破且反抽不能收复则观察退出 |
| 周线W底/头肩底 | 前高颈线明确、收盘越过颈线、量价时后续确认 | 重新跌破颈线且无力收复 |
| 右侧底部反转 | 下跌结构破坏、反弹前高突破、低点抬高、回踩确认，避免只看底背离 | 再创新低或回到原下降结构 |
| 缠论结构候选 | 分型/笔/线段及已完成次级别走势类型可核验，有中枢ZG/ZD与首个离开/回抽 | 任何结构缺项则只观察；不能把平台突破改名“三买” |
| 存量市场区间 | 反复确认上下轨、量能不支持持续趋势，区间下沿观察、上沿减仓 | 放量收盘突破并回踩确认后退出区间策略 |
| 基本面左侧 | 盈利与估值有安全边际、资金可以应对继续跌、分批试错 | 财报逻辑或行业假设失效时重新核验 |
| 短线情绪首板 | 板块情绪与封单/换手数据真实，具严格止损及执行条件 | 破位、炸板、流动性丧失、连续跌停风险 |

## 6. 第五层：卖点、持仓与仓位管理

- **长线仓**：研究企业盈利、行业周期、估值透支、现金流/竞争力改变，不用单根5分K线死叉处理多年持仓。
- **波段仓**：前高压力、放量长上影、高位放量滞涨、MA20/60及周线结构破坏、有效跌破最近重要回调低点、移动止盈、日/30分背离。
- **短线仓**：提前定义触发K线级别、交易制度、次日能否出场、滑点费用；30分卖点是作者经验，不代表必须立即全仓退出。
- **减仓与加仓**：只有额外确认信号、组合预算和风险回撤控制允许时讨论加仓，不能下跌一路摊薄成本；在压力区可分批减仓，突破后再按新结构重新评估。
- **止损计算**：账户权益×可承受单笔风险比例÷入场与结构失效位之间的差额，形成理论数量上限；扣除可用现金、组合集中度、交易单位、滑点与流动性。止损价不能保证成交。
- **缠论区间套**：只用于已充分识别的更大级别背驰段向小级别细化，不能把短线MACD底背离当成长期趋势一买。详见chan-primary-vs-mi-sky.md。
- 不根据历史文章中的50%、80%、固定时间窗或特定个股点位为用户默认设置仓位。

## 7. 输出固定结构

1. **结论及观察日期**（行情来源和最后已完成交易日）。
2. **行情类别**（趋势/震荡/下降，及大盘、行业共振与冲突）。
3. **公司和估值**（最低限度财务数据与潜在反证）。
4. **七级别技术矩阵**（没有对应K线就标NA，不从日K合成分钟K）。
5. **重要支撑压力区间**（强弱、形成依据、确认时间、跨周期重合、模型容差）。
6. **筹码、成交量、均线粘合与MACD等辅助信号**（严格区分模型）。
7. **候选买点**（现已符合/仍需哪个后续信号/因何失效）。
8. **候选卖点**（入场类别匹配的止盈/止损/减仓触发器）。
9. **风险与账户适配**（仓位预算、尾部风险、交易制度及数据缺口）。
10. **证据清单**（用户资料ID+条目/课次/日期、行情或财报来源、作者原意和独立推演分开）。
11. **下一次复核触发器**（哪根已完成K线、哪份财报、哪次行业信号）。

只有资料里可以确认的观点才标记为作者原意。其他通用量化公式/阈值/推论必须以独立研究参数显示。新增资料不得悄悄覆盖过去的历史判断；保留版本和冲突说明。
