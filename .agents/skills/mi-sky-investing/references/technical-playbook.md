# 实操技术分析手册：均线、量能、结构、策略

> 本文件独立归纳 Mi姐（Mistery/Sky）资料中的操作方法。它并非作者本人发布的最新版操作规范，更不表示任何规则已被证明有稳定正收益。每个结论区分 [作者原意]、[计算规范]、[框架推演]、[外部事实]。来源编号参见 source-index.md。

## 0. 不可跳过的操作顺序

1. 明确股票代码、市场、观察日、投资期限、是否持仓及成本价。未知则标记未知。
2. 从可靠渠道取得同期的**日/周/月 OHLCV** 数据（开、高、低、收、量）；核对交易日、复权方式、成交量单位、停复牌、除权及交易制度。
3. 先大盘与行业，再月线/周线，最后日线与60分钟线。小级别信号不能直接替代大周期拐点。
4. 依次计算均线及斜率、量比及量价组合、支撑压力、突破/回踩、MACD（若有历史数据和一致口径）。
5. 明确策略模式：上升趋势回踩、右侧突破、左侧价值布局、箱体波段或空仓观望。不能混用。
6. 最后才讨论入场条件、失效条件、风险预算、止盈或减仓逻辑、复盘触发器。

## 1. 均线系统：需实际输出数值

| 指标 | 用途 | 来源及性质 |
|---|---|---|
| MA5 / MA10 | 短线趋势、短线持有和回踩观察 | T00 §25、§29；[作者原意] |
| MA20 | 波段支撑/压力、520战法核心线 | T00 §23、§24、§26；[作者原意] |
| MA60 | 中期方向与MA5>MA20>MA60排列 | T00 §1、§22；[作者原意] |
| MA120 / MA250 | 更长周期参考，不应作为所有股票必用的进出场线 | T00 §25提及长线均线；M07个别标的250日线；[作者原意/适用有别] |
| MA斜率 | 下跌从陡到缓、走平、向上，是否已出现交叉和回踩验证 | T08 §409、§410（2026-10-21）；[作者原意] |

**标准计算**：[计算规范] MA_n(t) = 最近 n 根**已完成K线收盘价**算术平均。MA斜率可报告 MA_n(t)/MA_n(t-k)-1；须注明 k 和级别，禁止把斜率阈值说成作者的标准。MA5金叉MA20 = 前一根 MA5<=MA20，当前 MA5>MA20；死叉反之。

**520战法** [作者原意，T00 §23（2025-03-01）、§24（2025-05-09）]：
- 观察多头：价在MA20上方、MA5上穿MA20、均线开始向上，观察量能是否同步放大。
- 观察回踩：趋势上行时股价回到MA20附近，不能仅因触线买入；需看是否守住、随后再转强。
- 观察失效：跌破MA20、MA5转弱或死叉，尤其与放量下跌共振。金叉、死叉是**候选信号**，不是单独的自动买卖指令。
- 2025年的技术篇 §1 给出“价格上穿MA60，MA5>MA20>MA60，放量/平台突破，MACD金叉”的**一个中短线策略示例**；其中“跌破支撑5%-8%、5-7日时间止损、单票20%-30%”均为**特定案例参数**，不作为所有账户默认标准。

**多周期** [T00 §22（2025-05-28）]：
- 月/周：定方向；日：确认整理、回踩及结构；60分钟：仅在大/中周期允许时观察精细入场。60分钟线应由实际分钟行情聚合，不能拿日K猜测。
- 周/月均线应对**该周期已完成K线**分别计算，不能将日MA20误称为月均线，也不能把最近不完整的周/月K当已收盘信号。

## 2. 量能系统：先计算，再解释

**需要展示的数据**：[计算规范]
- 当日成交量 V_t、成交额（可得时）、近5/20根均量 VMA5 / VMA20。
- 相对量能 RVOL20 = V_t / 之前20根已完成K线的平均成交量。为避免把今天计入分母而稀释信号，默认**不含当日**；必须注明这一计算口径。
- 量价变化：收盘涨跌、当日成交量相对前一日的比例、最新涨跌所处的位置、是否临近前高/前低。
- 对全市场指数需单列市场成交额，不能将个股成交量、沪深成交额和全A成交额直接混比；跨年份总额需考虑市场结构变化。

**典型组合**：[作者原意，T00 §1、§28、§296；T08 §426、§449]：

| 价格与成交量 | 研究解释 | 操作前的必要验证 |
|---|---|---|
| 放量上涨并突破关键位 | 候选上攻与资金参与增强 | 收盘能否越过压力、后续能否站稳、板块是否配合 |
| 缩量回踩上涨趋势线/MA20 | 候选健康回踩 | 是否未破支撑、下一次上涨能否重新放量 |
| 放量下跌并跌破关键位 | 候选卖压增强和趋势破坏 | 看收盘有效性、反抽是否重新站稳 |
| 高位放量但冲高回落 | 候选承接不足/压力明显 | 与前期成交密集区、实体和上影线、连续K线验证 |
| 低位缩量、跌不动 | 候选筑底观察 | 还需高低点结构与右侧确认，不能仅因缩量认定见底 |
| 缩量上涨或无量反弹 | 趋势持续性待检验 | 是否仍处下降趋势及是否触碰强压力 |

**禁止伪造阈值**：原文多用“放量明显”“缩量回踩”，并未对所有个股给出统一的1.5倍或2倍标准。工具可以报告RVOL20数值；若使用用户自定阈值（例如1.5倍），须清晰标记 [参数假设]，不得称为作者原话。

**关于“主力”**：单凭成交量与K线不能证明具体投资主体、真实持仓成本或主动交易意图。采用“可观察现象→若干可能解释→需要的额外证据”的结构；“机构吸筹/出货”只可作为假说。

## 3. 支撑压力、趋势与右侧抄底

[作者原意] T08 §417（2026-10-23）：重视大周期级别的支撑/压力及趋势背景。T08 §426（2026-10-24）给出右侧抄底的**五项观察**：
1. 下跌结构被破坏：停止持续创新低，并突破前一个重要反弹高点。
2. 低点抬高：回踩形成更高的低点。
3. 重要位突破时成交量配合；放量不是必然成功。
4. 突破后的回踩站稳，形成压力转支撑，再次转强。
5. RSI/MACD底背离只作预警，不能代替价格结构确认。

**“量、价、时”复核**：[作者原意，T07 §339（2026-10-12）、T08 §426]：价格以**收盘**越过事先划定的关键位；量能与近期可比；后续K线不迅速跌回原区间。具体确认天数并无全市场统一固定值。

**压力支撑画法**：[框架推演]
- 事前用可观察的前高/前低、密集成交区、箱体上下沿、周/月重要拐点标出**价格带**，而非虚假的精确到分的单一数字。
- 突破后对旧压力位观察回踩是否守住；破位后对旧支撑位观察反抽能否站回。
- 标注每个价位的基准日、级别、形成依据和失效条件；历史案例点位不可复用于当日交易。

## 4. 价量均线综合检查卡（逐条填“是/否/未知”）

| 序号 | 观察问题 | 需要的证据 |
|---|---|---|
| 1 | 大盘周/月级别是否允许新增主动风险？ | 大盘走势、宏观、市场成交额 |
| 2 | 所在板块是否强于基准？ | 板块和指数同期收益、景气/基本面 |
| 3 | 月/周线是否已扭转下降结构？ | 已完成周/月K、前高前低、MA方向 |
| 4 | 日线价是否位于MA5/20/60之上？ | 计算数值及数据截止日 |
| 5 | MA5、MA20斜率及金叉/死叉如何？ | 本次、上次均线及交叉判定 |
| 6 | 是否放量突破或缩量回踩？ | 当前及历史相对量能、位置 |
| 7 | 关键压力/支撑在何处？ | 前高前低/密集成交区/趋势线 |
| 8 | 已满足突破→回踩→再转强链条吗？ | 时间顺序及后续价格结构 |
| 9 | MACD/RSI是否支持或反证？ | 口径、数据、使用边界 |
| 10 | 何种证据出现时撤销原判断？ | 事前写定的逻辑及价格条件 |

结果标签：**趋势机会待确认 / 候选回踩 / 候选右侧突破 / 下降趋势风险 / 震荡无优势 / 数据不足**。禁止将其渲染为概率或“必涨”。

## 5. 四种交易方案，必须写成条件

**A 趋势回踩**（T00 §23、§28）：前提为行业/大盘及较大级别趋势不弱；日K回踩MA20或已划定的趋势支撑，量缩且重新企稳，才进入候选；若放量跌破并持续失守，方案失效。

**B 右侧突破**（T08 §426）：先满足前高突破、量能、低点抬高；耐心等待回踩站稳并再度走强；反向跌回原箱体或失守新支撑时，撤销突破假设。

**C 存量震荡波段**（T08 §449，2026-10-29）：有明确定义的箱体范围、成交量低迷且未形成持续增量趋势时，优先控仓、等待区间边缘；若形成确认突破，退出原箱体策略。

**D 大周期左侧布局**（T06 §204；T08 §425-430）：只有基本面、估值、安全边际已独立核验，才讨论分批、低估值布局；不以MA金叉作为唯一前提，也不使用短线技术止损替代长线逻辑失效，必须保留应对继续下跌的资金计划。

## 6. 仓位、止损、止盈的可计算表达

- [框架推演] 每笔允许损失金额 = 账户净资产 × 事先明确的单笔风险预算比例。
- 理论数量 = 允许损失金额 / (预期成交价 - 结构失效止损价)，仅当差额为正且风险预算、价格均由用户提供；再向下取整到市场最小交易单位，并扣除费用、冲击成本以及跳空风险；这只是**基于止损距离的风险约束上限**，不是实际可保证亏损上限。
- 再与组合集中度、可用资金、日均成交量和相关性约束取更小值。
- 持有期间区分：短线趋势破坏、日线MA20失守、周线拐点破坏、企业基本面失效。这些对应不同交易模式，不能一律“一根跌破就卖”。
- 历史资料中有特定时期的五成、七八成等仓位案例（T00 §40、§42），亦有空仓/减仓场景（T08 §462），**不得将任一比例设为用户默认仓位**。

## 7. 实际输出示例（只演示格式，不提供虚构行情）

**标的 / 观察日期 / 复权口径：** 数据源、截至时点；无法取得真实行情时直接标注“未取得”。
- MA5 / MA10 / MA20 / MA60 / MA120 / MA250：逐项列数字及方向；缺样本则写“样本不足”。
- MA5×MA20：本次是否出现真正交叉（需上一根均线值）或仅持续多头排列。
- 成交量、VMA5/20、RVOL20：逐项列数字、单位和计算方法。
- 结构：最近已确认前高、前低、关键支撑压力；不把盘中瞬时价当有效突破。
- 量价组合：放量上涨、缩量回踩等，注明比较基准。
- 大盘与行业：与个股信号的相互印证或冲突。
- **策略A / 策略B / 观望**：明确进入前提、所需新证据、失效位置、持有周期及适配条件。
- **反证**：至少两个否定当前分析的证据。
- **来源**：作者资料编号/条目/日期，市场数据来源/更新时间，参数假设单列。

可运行工具：scripts/analyze_ohlcv.py。它读取用户提供的日/周/月 CSV，计算SMA与相对量能，给出候选结构和数据缺口。**它不抓取实时行情、不自动下单，也不根据未验证阈值生成“确定买卖”指令。**
