# 缠论结构模块：原始定义、Mi姐应用、可执行检查

独立方法说明，2026-11-04。关联新增资料 C01《缠中说禅：股市技术理论》及 C02《教你炒股票108课》，均为用户云盘收集的编订版。缠论并非Mi姐原创。参照《教你炒股票》第17、20、21、24、25、27、29、33、37、44、53、61、62、67、71、72、90、108课。仅保留必要概念和自主操作说明，不上传原书正文或图片。

## 1. 分清三套层次

| 层次 | 指什么 | 可以由什么判定 | 不等价于 |
|---|---|---|---|
| K线时间周期 | 5/30/60/120分钟、日、周、月，单位为固定时间窗 | 同一时区、交易时段、已完成OHLCV直接重采样 | 缠论定义的走势级别 |
| 几何走势结构 | 分型、笔、线段、走势类型、中枢 | 一套事先确定的包含关系处理、分型/笔/线段和次级走势划分规则 | 任意3根K线重叠、MA缠绕 |
| 动力学 | 背驰、盘整背驰、同级别分解、区间套 | 同级完成走势A/B/C和动能的可比证据，次级别逐级确认 | 单根K线MACD顶/底背离 |

原始缠论使用“1分钟、5分钟”等作为实例，但数据K线周期与通过递归结构识别的走势级别不应强制一一对应。同一日线图也可能包含复杂的次级别结构。没有足够细的完整数据时，不做严格一买/二买/三买判断。

## 2. 从K线到中枢的审计流程

1. 取得按时间递增、复权一致且已结束的K线。A股5分钟K线按实际交易时段合成更大时间窗；不用尚未完成K线预判正式分型。
2. 对K线包含关系按明确的走势方向规则处理。包含方向、局部同高同低、边界取值、不同流派“新笔/老笔”要求都必须写入策略参数；不能悄悄变更。
3. 识别顶底分型：常用三根经处理K线的顶点和底点，其中中心高低点与左右满足定义；须右侧完成才能确认。普通“左右各两根”摆动点只是市场结构proxy，不等于缠论原始分型。
4. 按事先声明的规则连接笔，再组成线段及次级别完整走势类型，记录起止日期、顶底价、来源K线以及尚未完成状态；出现分歧时必须显示两种可能。
5. 某级别中枢由至少三个连续已完成的次级别走势类型的重叠价格区间构成。若第1/2/3段价格区间分别为[low_i,high_i]，将三段价格区间求交，ZD_proxy=max(low_1,low_2,low_3)、ZG_proxy=min(high_1,high_2,high_3)，只得到**几何重叠代理值**，要求ZD_proxy<ZG_proxy。原典第20课中枢边界涉及与中枢方向一致的Z走势段及其交集，不能把这三个价格区间代理值无条件视作正式ZD/ZG。严格中枢还必须独立核验已完成走势类型、级别及分解法。
6. 中枢延伸、升级、走势的重新组合应在当时已知信息下逐步更新；不得等历史走完再倒推“最佳笔和线段”冒充当时能观察到的信号。

脚本 scripts/chan_segment_check.py 是**批量几何代理筛查**：只检查用户提供的同级已完成次级走势价格区间，输出五段形态候选。更保守的 scripts/check_chan_setup.py 用于**指定中枢个案审查**：要求用户明确提供经独立确认的正式ZD/ZG、5个已完成且已核验的次级走势类型、方向/起止日期及“第一次回试”的标注；只核对价格边界关系，不自行认证原始走势划分。两种工具都绝不从原始K线自动生成完整缠论走势级别。

## 3. 第一、第二、第三类买卖点

| 分类 | 原始课程的结构要点 | 必需确认 | 典型误判 |
|---|---|---|---|
| 一买 | 某级别下跌趋势末端，最后中枢下方出现该级别下跌的趋势背驰 | 至少完整同级别可比较走势及背驰结构；小级别向上转折辅助确认 | RSI低于30或股价大跌便称一买 |
| 二买 | 第一类买点后出现次级别上涨，再出现次级别回跌的结束位置 | 两次次级走势确已完成；不要臆测回调已经结束 | 第二根阳线或MA5金叉便称二买 |
| 三买 | 次级别向上离开已经形成的本级中枢，后续第一次次级别回试，其最低点不跌破ZG（中枢上沿；触碰ZG是需明示的边界情况） | 中枢定义与离开段、回试段均为已完成的次级别走势类型 | 任何一个收盘突破、只看一根缩量回踩、无次级别结构便称三买 |
| 一卖 | 上升趋势末端对应级别的上涨背驰 | 必须与交易级别一致 | 任一5分钟顶背离就断言日线见顶 |
| 二卖 | 一卖后下跌、再次上涨的次级走势结束点 | 完整次级别确认 | 反弹一天便认定二卖 |
| 三卖 | 次级别向下离开中枢，第一次次级别反抽，其高点不升破ZD（中枢下沿） | 下降离开与反抽完整，之前中枢有效 | 把跌穿一根K线的前低当三卖 |

## 4. 背驰、盘整背驰、区间套

- 严格背驰：先识别同级别上涨/下跌的中枢及走势段，在可比方向段观察动力衰减；不能仅凭两个随机MACD峰谷判断“缠论背驰”。C01第二章第四节；C02第24、25、27、37课。
- 盘整背驰：仅限盘整结构比较。原作者认为它与趋势背驰有不同的操作含义，不能直接宣称其为同级别一买。
- MACD：DIF/DEA、柱面积与零轴是背驰辅助。先有可审计A/B/C走势段，再比较同级别动能；计算窗口、红绿柱乘数和数据源一致。
- 区间套：上一级别已出现转折候选后，向已完成的下一级别结构递归查找细化定位；C02第61课。不能因为日/30分钟/5分钟都超卖，就称标准缠论区间套。
- 级别不可跳跃：低级别背驰可能只触发本级调整，也可能演化为更大级别转折，不能据较小级别背驰就断言较大级别必然反转。C02第29、44课；T00 §67及§260的分钟背驰周期仅可作为作者经验。

## 5. Mi姐方法与缠论原始定义的映射

| Mi姐材料中的实操口径 | 缠论严格关系 | Skill处理 |
|---|---|---|
| T00 §85：月线周期、周线趋势、日线找机会，60分金叉买、30分死叉卖 | 属于均线/技术择时，不等于缠论一二三买卖点 | 保留“Mi姐均线择时”，还需量价和周期确认 |
| T00 §177：30分钟箱体突破回踩不破，举例“三买” | 是三买几何现象的简化表述；缺真实次级别走势类型不足以确认 | 改称“中枢突破回抽形态候选”，另给严格三买结果 |
| T00 §179：中枢抬高、突破新中枢的“三买” | 与严格定义的第一次次级别离开、回试不入中枢之间有差异 | 保留历史表述，严格三买按第20课检查 |

## 6. 实操输出：双轨比较

价格行为轨道：月线/周线方向，日线箱体/均线/量能，120/60分钟趋势，30/5分钟择时，日周支撑及筹码峰，普通突破/回踩条件。

缠论结构轨道：当前明确的操作级别，已完成次级别分型/笔/线段，中枢[ZD,ZG]，目前中枢内/上/下，次级别离开与首次回试，严格一/二/三买或卖是否满足。不足则标注“未确认”及所需次级数据。

最终报告须同时说明：
1. 日/周/60分钟均线与前高前低形成的普通支撑/压力及计算口径。
2. 中枢ZD/ZG、分段完成状态、三买/三卖候选，或因证据不足不判定。
3. 两轨一致处与冲突处；不能把相关指标数量当成独立概率票数。
4. 人工划段主观性、历史重画风险、未来函数、跳空、交易制度和仓位。
5. 没有分段数据时，仅给价格行为分析，严格缠论写“不可判定”。
6. 即便check_chan_setup.py得到third_buy_geometry_candidate，也只代表**基于人工提供并声明已核验的结构输入**符合几何边界，程序不能独立证明走势类型已经完成，不得改写为“自动确认三买”。

## 7. 最小可验证情形

| 输入 | 结论 |
|---|---|
| 仅日K | 只算均线/量价及普通支撑；缠论5分钟次级结构数据缺失 |
| 仅5分钟K但未按规则建笔、线段和走势 | K线技术候选可算；严格中枢及三买仍未确认 |
| 有三段人工标注、已完成、同级别次级走势 | 可以计算候选中枢ZD/ZG，但须核验段级别 |
| 三段中枢成立、后续次级别上离开及第一次回试均完成，低点≥ZG | 五段几何模板吻合；只有全部分段经过严审才可称正式三买 |
| 回试跌回中枢 | 不符合该中枢三买定义，重新按中枢延伸或更大级别盘整分析 |
| 三买后价量恶化或扩展出大级别盘整 | 三买不保证趋势继续，重新评估退出策略 |
