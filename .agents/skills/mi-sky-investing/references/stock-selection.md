# 选股实操：筛方向、股性、强度、形态与入场资格

本手册根据用户提供的Mi姐/Mistery/Sky资料独立归纳，不声称作者本人验证或认可。编号见 source-index.md。所有数据必须真实可核验；阈值如非作者原文，须明示是研究参数。

## 1. 初筛：先大盘、再板块、最后个股

- 大盘指数用于判断整体风险和组合仓位环境，行业指数用于判断方向与板块强弱，个股寻找具体买卖点。T07 §338（2026-10-12）。
- 判断月/周趋势和行业景气，业绩与估值同步核验，剔除停牌或交易制度不适合的标的；不得凭热点/单日大阳线入选。
- 先选择实际策略周期：长期价值、趋势波段、短线情绪。各种类型不可混用买卖规则。
- 股票池分类为“机构趋势型候选”“短线情绪型候选”“交易特征异常且待核验”，**仅凭K线不可证明持仓主体、主力动作**。T00 §100-103（2025-05）、§302（2025-12-20）。
  - 趋势候选：产业业绩有支持，换手与波动相对平稳，温和放量、阶梯式抬升、回踩缩量。关注中线而非涨停频率。
  - 情绪候选：短时成交量和换手快速增大，涨停/炸板、剧烈波动、热点驱动。需独立短线体系。
  - 异常控盘“庄股”仅可作为待核实市场特征，禁止根据走势推断具体操纵者。

## 2. 原文中真实存在的强势股参数

T00 §196《强势股选股指标》（2025-09-20）给出以下**文章内参考参数**，不代表全市场通用的买入规则：

| 类别 | 该文列出的观察指标 | 判定约束 |
|---|---|---|
| 均线 | MA20大于MA60大于MA120，价格在MA20上、回踩不破 | 用真实已完成K线复算 |
| 趋势动量 | RSI超过50且上升，RPS超过90，MACD DIF在0轴上且金叉、柱扩张 | 不同信号未必同期成立 |
| 成交量 | 5日均量超过10日均量，上涨放量、下跌缩量，突破相对放量“1.5倍以上” | 文章特定阈值，须记录比较基准 |
| 换手 | 日换手3%至7%作为活跃参考，持续超过15%提示风险 | 需确认流通股口径及板块 |
| 盈利质量 | 净利润同比增速超过20%、毛利率稳定/改善、行业领先 | 财报发布日期与市场当时可得信息 |
| 资金观察 | 连续3日“主力净流入”、单日占成交额5%以上、机构增持 | 数据商“主力净流入”属于代理算法，不等于可核实的机构交易 |

**RPS缺失问题**：原文没有唯一指定RPS计算窗口、完整股票池和复权口径。若没有对应完整样本，只能写“作者同口径RPS不可计算”，不得在少量自选股票中假造全市场RPS。

**突破量比区别**：2025年的§196给出1.5倍参考值，2026年T07 §339强调量价时综合确认，没有设置所有突破都必须1.5倍的统一规定。不能将局部条目阈值写为不可更改的作者铁律。

## 3. 按交易目标建立不同候选池

| 股票池 | 研究规则 | 历史出处 |
|---|---|---|
| 月线主升浪前期 | 长期底部箱体、均线粘合走平，出现有效向上放量突破，突破后守住结构 | T07 §320（2026-10-04） |
| 周线盘整突破 | 周线横盘结束，W底颈线/箱体突破，回踩原压力未破再走强，避免追连续大涨 | T00 §128（2025-06-30） |
| 机构趋势波段 | 企业盈利和行业逻辑可核验，周/月级别向上，日线回到MA20或趋势线缩量、重新转强 | T00 §100、§212、§296 |
| 形态筑底观察 | W底、头肩底、三角形收敛；须突破颈线/关键压力并后续确认 | T00 §61（2025-03-01） |
| 超跌反弹候选 | 原为强势趋势股、因大盘情绪被动下跌，反弹仍须确认；不优先选择连续跌停且基本面恶化股 | T00 §149（2025-09-05） |
| 低估值长期布局 | 行业空间、现金流、竞争优势、估值和盈利改善须通过独立事实核验 | T08 §438、§452（2026-10） |

T00 §296（2025-12-18）进一步强调七项观察：长期整理、下跌趋缓、量能健康、回调缩量、关键位置承接、突破有力、走势平稳。把它们当作待核验的价格行为线索，不等于已知主力真实成本。

## 4. 特殊短线策略只能单列

T00 §205-206（2025-09-23）提出首板入自选、看封成比，随后1至2日观察回调买点。原文封成比参考区间为0.2以上、0.1至0.2、0.1以下。它只适合短线策略研究，不能混入中长线策略，也不能仅凭瞬时封单断定次日走强。缺盘口快照、实际封单单位或撮合状态时不得生成数值。

## 5. 每只股票必须输出候选审核卡

1. 证券代码、市场、研究周期、复权及行情时间。
2. 交易模式：趋势候选、情绪候选、长期价值候选或不适合；分类不代表实际资金主体。
3. 大盘与板块状态、行业需求、企业盈利和估值。
4. MA20/60/120、RSI、MACD、VMA5/10、成交量、换手；缺一项标记未知，不能补造。
5. 如果需要RPS，明确窗口、股票池、复权口径，缺完整数据则写未知。
6. 目前为箱体内、突破候选、回踩待确认、下降趋势或已失效中的哪种。
7. 精确列出可观察的入场前提、反面证据、失效位置和复查日期，**不能直接变成下单指令**。

## 6. 其他限制

- 原文不同年份的“机构参与”“庄家操盘”解释都不能凭价格数据单独证实。
- 全量资金流不能用供应商衍生指标模拟；必须写清供应商和算法口径。
- 未经回测不得声称RPS>90或1.5倍成交量具有确定成功率；回测必须控制幸存者偏差、可成交性、财报发布日期和交易费用。
- 本手册只筛选值得进一步研究的标的，具体买卖点与退出请看 price-action-and-exits.md。
