# 走势分类、买点、卖点与持仓操作手册

根据用户提供的Mi姐投资资料，独立整理为条件式研究步骤。来源编号见 source-index.md。原文含夸张预测和无法直接验证的“主力行为”叙述，本手册只保留可观察的价格、成交量和财务条件；不保证盈利。

## 1. 先定义行情状态，再选对应的策略

| 状态 | 可观察证据 | 原文对应思路 | 失效/切换时机 |
|---|---|---|---|
| 上涨趋势 | 高点、低点依次抬高，月/周方向向上，日线回踩不破，量价支持 | 持有为主，回踩观察，不因小级别背离频繁离场 | 周线支撑有效跌破、产业逻辑证伪或高位放量破位 |
| 下降趋势 | 高点、低点下降，反弹乏力，放量下跌与缩量反弹 | 控仓或观望，警惕把反弹误判为反转 | 重要前高突破、低点抬高和回踩确认 |
| 震荡区间 | 明确箱体上沿/下沿，多次往返且缺方向 | 区间下沿观察低吸、上沿观察减仓，区间中段减少交易 | 经量、价、时间验证的有效突破/破位 |
| 筑底观察 | 下跌趋缓、低点可能抬高、均线变平 | 只列候选，不提前宣称大底已确认 | 破新低或完成反转确认 |
| 高位筑顶风险 | 量价背离、重要高点屡次失败、长上影放量、关键位破坏 | 主动评估退出而非盲目加仓 | 价格强势放量收复并站稳压力、前判断反证 |

**出处**：T08 §458（2026-11-01）；T07 §330-331（2026-10-10）；T00 §101、§190、§293。一个股票在月线和日线可出现不同状态。必须分别报告，不应因某日大阳线改变月线结论。

## 2. 五类“候选买点”及三段确认

**类型A：趋势回踩买点**（T00 §61、§23、§28）
- 大盘与板块环境不反对；周/月趋势上行，股价回到日线MA10/MA20、原支撑或上升趋势线。
- 回踩期间量能减弱，价格未有效失守关键位，并在随后K线重新走强。
- 若放量击穿支撑且反抽未恢复，则撤销“健康回踩”的解释。

**类型B：箱体/旗形/三角形突破**（T00 §61、§213；T07 §339）
- 先在入场前画出箱体上沿/下降压力线/前高。
- 报告突破K线的收盘价与相对成交量。盘中触及或刺穿不等于收盘站稳；放量也不能单独证明真突破。
- 原文在T07 §339建议观察后续1至3根K线，并特别指出这**仅为参考而非统一确认天数**。
- 更谨慎者可等“突破→缩量回踩原压力→重新走强”；失效为收盘重回原区间且后续无法收复。

**类型C：W底/头肩底颈线**（T00 §61、§128）
- W底至少两次有效探底，第二低点不再明显创新低，颈线突破时有量价确认。
- 头肩底需要可定位左肩、头部、右肩、颈线；突破后回踩确认可作为观察点。
- 颈线未破或量价不足时标记“筑底候选”，不叫已形成买点。

**类型D：大周期左侧低估布局**（T06 §204；T08 §402、§425-430）
- 独立验证估值、行业、企业持续盈利和现金流后，才考虑分批观察；底部尚无确认，风险预算需能容忍继续下跌。
- 在尚未完成右侧确认时不能暗示成功概率已经提高，也不能用看似便宜的价格替代基本面判断。

**类型E：更高一级周期主升启动**（T07 §320，2026-10-04）
- 月线长期箱体、均线收敛并逐渐上拐，放量向上脱离长期区间，随后仍守住关键结构。
- 这与小级别日内“首板追涨”本质不同，需周/月证据支持。

**三段流程**（T08 §426，2026-10-24）：止跌观察 → 突破原反弹高点并形成高低点转强 → 重要突破位回踩后再度转强。MACD/RSI背离仅为辅助预警，不能代替结构确认。

## 3. 七类候选卖点与对应动作

| 观察信号 | 可能意义与适用策略 | 反证/动作条件 | 来源 |
|---|---|---|---|
| 高位放量跌破前低、箱体下沿 | 趋势被破坏，技术型持仓应评估退出 | 看收盘有效性与反抽，不能只看分时刺穿 | T00 §59、§62 |
| 双顶/头肩顶颈线放量跌破 | 顶部形态候选获确认 | 颈线有效跌破后持续无法收复 | T00 §59、§62、§102 |
| 上升趋势线/MA20/MA60有效失守 | 趋势衰弱；短线波段规则优先 | 与原入场周期一致，长期基本面仓位单独判断 | T00 §62、§64 |
| 高位放量长上影/放量滞涨 | 压力区抛压明显、候选分批止盈 | 不单凭一根K线断言主力出货，观察后续结构 | T00 §214；T08 §427 |
| 缩量新高、反弹高点依次降低 | 趋势动能衰弱、潜在波段高点 | 压力区附近优先观察减仓机会；趋势若恢复则改变判断 | T00 §59；T08 §427 |
| 下跌趋势B浪反弹至压力 | 可能仍是下跌结构中修复行情 | 不把反弹等同趋势反转，明确止盈计划 | T00 §269；T07 §330 |
| 趋势波段中的移动止盈 | 最近重要回调低点随趋势上移 | 有效跌破最近关键低点触发规则复核或按计划退出 | T08 §427（2026-10-24） |

作者在T08 §427进一步给出三类卖出方法：接近压力位分批止盈、有效跌破最近重要回调低点、随波段逐步上移保护性退出水平；**趋势上涨中不要简单因为“已经涨多”清仓**。

## 4. 复杂调整与顶部风险

- T00 §134（2025-07-23）把短暂停顿、简单调整、复杂调整区分开，并给出若干**经验时间范围**。这些时间数字不能被预测模型当作必然发生的未来周期。
- T00 §101、§102、§214：情绪票可能快速炸板/高开低走；机构趋势票可能高位盘整、逐级弱化、慢速跌破关键均线。两种股性对应不同退出速度。
- T00 §190：高位巨量冲高回落、反复磨顶、尾盘急拉而次日低开，都只是风险线索，不能单独认定真实资金意图。
- T00 §257（2025-11-05）提出“30分钟找卖点，60分钟找买点”，作为**作者的交易习惯**而非可验证的统一规律；未取得分时数据时不得推算。

## 5. 缠论原典、Mi姐实操口径与波浪理论的关系

- 新增C01《股市技术理论》和C02《教你炒股票108课》，已可核对：T00 §61、§66、§177、§179中“箱体突破回踩不破”“新中枢突破”的表述，部分是Mi姐对缠论的便捷化应用，不应直接当作严格的三类买卖点定义。详情见 chanlun-framework.md。
- 严格三买：先建立符合定义的本级走势中枢，之后完整次级走势向上离开，随后第一次完整次级走势回试，其低点不跌破中枢上沿ZG。严格三卖反向，回抽高点不升破中枢下沿ZD。原课第20/21课明确提出次级别及第一次的条件。
- 中枢是至少三个连续**次级别走势类型**的重叠；普通三根K线交叠、均线粘合、普通价格箱体、MA/MACD交叉都不能直接证明严格缠论中枢。
- 仅有OHLCV没有符合事先规则的完整分型/笔/线段及次级走势时，**正式缠论买点不可判定**。scripts/chan_segment_check.py只能核对外部标注分段的几何结构，不能自动确认缠论级别。
- C01编订文献把三卖的ZD误写成“上沿”，经C02第20课及公开课程核对应为**下沿**。原作者历史上的“绝对”“100%”是理论主张，不作为交易成功率。
- T00 §269的ABC调整浪、0.382至0.618反弹等斐波那契标记属于主观浪型划分，不能据此得出确定底部时间或目标价。
- T00 §196的量能1.5倍是个别2025文章参考，T07 §339侧重突破后的价量时验证，不能固化成普适阈值。
- T08 §438与T00 §129强调买卖逻辑同周期：长线按产业、估值与竞争力失效判断，技术短线按入场形态和止损纪律退出。

## 6. 可直接复用的股票操作检查表

在任何**具体个股**分析中，一律逐项填写以下条目，不可省略：

| 栏目 | 答案 |
|---|---|
| 数据时点及口径 | 证券代码/交易所/观察日/时区/复权/数据商 |
| 月线/周线/日线/60分钟状态 | 上升/下降/震荡/未确认；分别提供证据 |
| 形态分类 | 长期箱体/W底/旗形/回踩/下降中继/不明确 |
| MA系统与量价 | MA5/10/20/60/120、VMA5/10/20、成交量及相对量能 |
| 关键位 | 已确认的最近高/低及支撑/压力带，形成依据 |
| 入场资格 | A/B/C/D/E模式中的哪一种，已满足和未满足哪些条件 |
| 退出触发器 | 趋势破位、前低失守、压力区滞涨、估值透支或基本面恶化 |
| 反面证据 | 至少2条，必要时评估交易制度与无法成交风险 |
| 资金约束 | 用户风险预算、止损距离、流动性、单票与行业集中度 |
| 下一步 | 未满足则等待哪条K线或哪项新事实，不直接发确定买卖指令 |
| 证据 | 作者条目/日期；最新市场数据网页或公告；额外假设 |

相关指标和统计解释也可交叉对照英文 Fidelity Technical Analysis (2026-06-10)、繁体中文统一证券技术分析帮助与简体中文投资者教育材料；这些只帮助理解指标，不证明作者的收益率。
