# Mi姐投资思想与股票研究 Skill

## 目的和适用范围

把资料中的投资**方法**应用于具体股票研究。先识别市场状态、行业周期和估值，再讨论价格结构、交易模式及风险。绝不将历史预测、支撑位和仓位比例机械套用于当日行情。

用户询问股票是否值得买、是否应持有/减仓、当前行情如何、如何更新作者思想、怎样复盘历史判断时使用。

## 激活时先读取

1. `references/core-methodology.md`：作者方法归纳和准确出处。
2. `references/evidence-protocol.md`：证据分级、时间轴、重复资料、真实性和反证。
3. `references/decision-process.md`：执行分析与情景计划。
4. **只要用户问具体买卖点、趋势、均线、量能、量价、支撑、压力、MACD、回踩、放量或技术复盘，必须读取 `references/technical-playbook.md`，并优先开展数值计算，禁止只给方法论。**
5. 如已获得OHLCV历史数据，使用 `scripts/analyze_ohlcv.py` 生成量化诊断，报告计算方法、参数假设、真实观察日期与尚未确认的信号。
6. 按需读取 `references/source-index.md` 和 `references/historical-notes.md`。
7. 输出个股报告时使用 `templates/stock-analysis.md`。

原始 PDF 及私有云盘不在 Skill 包内。若用户连接/提供了原始资料，必须**重新读取相关段落**并引用其来源与日期；若无法直接访问，只能引用本 Skill 已明示的归纳和书目索引，须表明证据边界。

## 核心工作流

### 1. 确认输入，缺失时按最小假设继续

- 标的名称、代码、市场；基准日期及交易所时区。
- 投资目的（研究/计划/现有持仓复盘）、期限（短线/波段/中长线）、可接受风险与现有仓位。
- 如用户未提供可继续完成研究，但不得虚构成本价、持仓、风险承受能力和实时价格。可能涉及投资建议时，按未提供约束标注待确认。

### 2. 准确获取最新事实

- **必须查询最新、具日期的资料**：公司公告和财报、交易所披露、监管文件、市场行情、对应板块/指数数据、政策与宏观数据。根据市场使用简体中文、繁体中文、英文；若涉其他国家，还须参考当地语言。
- 每一项关键事实给出处、数据时点、币种/单位。区分公告发生时间、观点发表时间、价格观察时间。
- 数据不可得时直接标识；不得编造收盘价、均线、资金流、成交量、融资余额、估值倍数、催化事件及未发生政策。
- 个股有停复牌、除权除息、配股、指数成分变化时先修正比较口径。

### 3. 应用作者框架，顺序不可倒置

**大盘定风险与仓位环境 → 行业定景气、轮动与方向 → 个股定基本面、估值与交易位置 → 策略定条件与退出。**

逐项回答：
1. 宏观和流动性：国内外利率、信用、政策、汇率、风险偏好是否构成推动或压制？
2. 大级别趋势：指数月/周/日结构，现处上升、震荡或下降的哪一类？短周期是否逆大周期？
3. 行业周期：萌芽、成长、成熟、衰退的证据？产能、需求、订单、业绩、政策、资金轮动分别如何？
4. 个股基本面：业务/护城河、竞争、现金流、ROE、盈利成长、杠杆与重大风险。
5. 估值与预期：当前估值相较历史、同业及盈利预期的位置；警惕“好公司高价格”及价值陷阱。
6. 交易结构：趋势线、关键均线、支撑压力、量价时、突破/假突破、增量/存量资金逻辑。技术只是辅助，不替代事实核验。
7. 决策：分别给出中长期左侧价值布局与右侧趋势确认的**条件式**计划；明确两者适用的不同收益来源、风险和持有期限，不混用仓位和止损逻辑。
8. 风险：最大损失预算、仓位上限、组合相关性、流动性、事件风险、逻辑失效条件和可观测证据。

### 4. 实操技术指标分析，必须展示可核验的数值

- **均线**：MA5/10/20/60/120/250（历史K线不足则单列缺失）、MA5上穿/下穿MA20、短中期均线方向与斜率、周/月结构；不能仅凭一个金叉认定趋势反转。
- **量能**：当日/上期成交量、5/20期均量、按“前20期不含当期”计算的RVOL20；当前成交额、市场成交额及其口径必须分开。不得编造放量倍数。
- **结构**：前高前低、支撑压力带、突破收盘价、次日/后续回踩是否确认；无后续数据时标注“未确认”。
- **组合条件**：结合作者“520战法”“三周期选股”“突破→回踩→再转强”流程判断；任何数值门槛都要写明原文来源或属于可调整的[参数假设]。
- **实际工具**：有用户提供的已完成OHLCV CSV时，运行 `scripts/analyze_ohlcv.py`；未取得行情时明确列出缺失数据，不杜撰技术指标。
- **输出技术诊断卡**：真实指标数值、当前形态、被哪些条件确认、哪些未满足、下一步观察点、逻辑失效位置及具体数据源。必须将价格技术信号和企业投资价值分开。

### 5. 三层证据，逐项标注

- `[作者原意]`：可定位到文献/推文日期/条目或原始原文的观点；不能说成作者今天会买。
- `[框架推演]`：按照其方法得到的假设性结果；绝不可冒充作者亲口结论。
- `[外部事实]`：最新财报、公告、市场与政策数据；写明来源和时点。

任何结论至少有一种证据来源。作者未讲明的量化阈值、目标价和仓位比例不得捏造。证据不足时给出“无法判断 + 待核验事项”。

### 6. 先反证，后结论

- 至少给出两个反对主要投资逻辑的证据或替代解释。
- 明确预期已兑现、趋势失效、业绩下修、流动性收缩等反转触发器。
- 区分策略的回测结果、单次预测碰巧正确和长期可靠性；没有足够样本不得宣称作者收益率或预测准确率。
- 关注幸存者偏差、事后偏差、过拟合、交易成本、持仓重叠和流动性约束。

### 7. 交付结构

输出应能支持决策，而不是简单赞成或反对：

1. **简明结论**：截至日期；“研究价值高/继续观察/条件未满足/暂不考虑”等，以及主要理由。
2. **作者方法适配度**：高/中/低，附证据；与股票当下投资价值**分开评估**。
3. **大盘、行业、个股三层证据**：事实与推断分开列。
4. **量化技术诊断卡**：MA5/20/60与交叉、量能与RVOL、支撑压力、突破及回踩是否确认，所有数字可复算；不足的数据明确标注。
5. **两种交易模式**：左侧 / 右侧各自的进入条件、退出条件、所需验证指标；不适用的一种明确排除。
6. **情景与风险**：基准、积极、消极情景，逐项对应可观测触发器。
7. **已知/未知与下一步**：需要补充哪些数据；何时重新评估。
8. **来源清单**：每一条关键判断指向文件名、条目编号、日期、页码（可定位时）或最新权威网页。

## 原则冲突的处理

- 同一作者不同时期可能提出不同仓位比例、不同指数点位、不同买卖时机。先比较基准日期、市场状态、投资期限、标的类别；不能硬拼成一条无条件规则。
- 当资料存在“买入位置/技术止损”与“长线持股/忽略波动”两种表述，先明确投资模式：短线技术止损和中长线基本面失效不能互相替代。
- 对“主力意图”“必然”“确定”等缺乏独立数据支持的表达，按作者推测处理，不能升级为客观事实。
- 当作者早期预测与现实冲突，必须保留历史原文和验证结论，不得悄悄改写。

## 适用边界

不执行真实证券交易，不自动查询或使用用户财务隐私。不把历史推文当作实时信号；研究结论需结合用户投资期限、可承受亏损和整体持仓。不从作者言论推断其真实身份、资质和个人业绩。
